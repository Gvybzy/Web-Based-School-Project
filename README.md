# 🏫 Rosales National High School — Web-Based School Project

A modern, responsive school website developed as a web-based school project for **Rosales National High School (RNHS)** in Rosales, Pangasinan.

The project aims to provide students, parents, teachers, and visitors with an accessible online platform where they can learn more about the school, its academic programs, facilities, events, values, and other important information.

##  Live Website

**[Visit the Website](https://gvybzy.github.io/Web-Based-School-Project/)**

##  Features

*  **Home Page** — Overview of Rosales National High School
*  **School Profile** — Information about the school's history and identity
*  **Academic Strands** — Information about ABM, GAS, HUMSS, STEM, and TVL
*  **Facilities** — Showcases school facilities such as the library, gymnasium, and lounge area
*  **School Events** — Displays school activities and community events
*  **Vision & Mission** — Presents the school's vision and mission
*  **Core Values** — Highlights the DepEd core values:

  * Maka-Diyos
  * Maka-tao
  * Makakalikasan
  * Makabansa
*  **DepEd Mandate** — Provides relevant educational information
*  **Contact Page** — School contact and location information
*  **Student Portal** — Dedicated area for student-related access
*  **Responsive Design** — Designed to work across different screen sizes

## Technologies Used

* **HTML5** — Website structure and content
* **CSS3** — Styling, layout, responsiveness, and visual design
* **JavaScript** — Interactive website functionality
* **GitHub Pages** — Website hosting and deployment

## Project Purpose

This project was created as a practical web development project to demonstrate the application of fundamental front-end development concepts.

It focuses on building a school website that is:

* Clean and organized
* Easy to navigate
* Responsive across devices
* Informative and accessible
* Modern compared to a traditional static school website

* Creating responsive layouts with CSS
